# Love Page • 杨淇超我爱你

一个极简但富有仪式感的告白网页，具有动态渐变背景、玻璃拟态卡片、霓虹发光标题、心形粒子爆炸、打字机效果与主题切换。

## 使用方法
1. 直接双击 `index.html` 打开（离线可用）。
2. 标题会以打字机效果显示“杨淇超我爱你”。
3. 点击「撒一把爱心」或在页面任意位置点击/触摸，会播放心形粒子爆炸。
4. 点击「切换主题」在明/暗主题之间切换（本地持久化记忆）。
